# Гайд по добавлению историй

## Новая структура папок

Теперь истории организованы по сериям и дням:

```
story/
├── The Whistling Bridge/          # Папка серии
│   ├── Day 1/                     # День 1 серии
│   │   ├── story.json            # JSON файл истории
│   │   ├── foto.webp             # Картинка для истории
│   │   ├── man/                  # Аудио для мужского голоса
│   │   └── woman/                # Аудио для женского голоса
│   ├── Day 2/                     # День 2 серии
│   │   ├── story.json
│   │   ├── foto.webp
│   │   ├── man/
│   │   └── woman/
│   └── Day 3/                     # День 3 серии
│       ├── story.json
│       ├── foto.webp
│       ├── man/
│       └── woman/
└── stories.json                   # Список всех историй
```

## Как добавить новую историю

### 1. Создайте папку для нового дня

Если вы продолжаете существующую серию (например, "The Whistling Bridge"), создайте папку `Day 4`:

```bash
mkdir -p "story/The Whistling Bridge/Day 4"
```

Если вы начинаете новую серию, создайте папку для серии и первый день:

```bash
mkdir -p "story/New Series Name/Day 1"
```

### 2. Подготовьте файлы

В папке дня должны быть:
- `story.json` - JSON файл с данными истории
- `foto.webp` - Картинка для истории (опционально)
- `man/` - Папка с аудио для мужского голоса (опционально)
- `woman/` - Папка с аудио для женского голоса (опционально)

### 3. Настройте story.json

В JSON файле обязательно укажите правильный путь в поле `folder`:

```json
{
  "id": "2026-09-02-new-story-day-1",
  "date": "2026-09-02",
  "slug": "new-story-day-1",
  "folder": "The Whistling Bridge/Day 4",  // ВАЖНО: правильный путь к папке
  "seriesDay": 4,
  "seriesTotal": 7,
  
  "title": {
    "en": "Story Title",
    "ru": "Название истории"
  },
  
  "summary": {
    "en": "Story summary in English",
    "ru": "Краткое описание на русском"
  },
  
  "levels": {
    "easy": {
      // Уровень A2
    },
    "intermediate": {
      // Уровень B1
    },
    "challenge": {
      // Уровень B2
    }
  }
}
```

**Ключевые поля:**
- `folder` - путь к папке от корня папки `story/` (например, `"The Whistling Bridge/Day 4"`)
- `seriesDay` - номер дня в серии (1-7)
- `seriesTotal` - общее количество дней в серии (обычно 7)

### 4. Добавьте историю в stories.json

Откройте файл `story/stories.json` и добавьте путь к новой истории в массив `stories`:

```json
{
  "stories": [
    "story/The Whistling Bridge/Day 4/story.json",
    "story/The Whistling Bridge/Day 3/story.json",
    "story/The Whistling Bridge/Day 2/story.json",
    "story/The Whistling Bridge/Day 1/story.json"
  ]
}
```

**Важно:** Истории в массиве должны быть в обратном хронологическом порядке (сначала самые новые).

### 5. Картинка для истории

Картинка должна называться `foto.webp` и находиться в папке дня. Код автоматически найдёт её по пути `story/[folder]/foto.webp`.

### 6. Аудио файлы

Аудио файлы размещаются в папках `man/` и `woman/` внутри папки дня. Названия файлов должны соответствовать уровням сложности.

## Пример полной структуры для новой серии

Если вы создаёте новую серию "The Mystery Library":

```
story/
├── The Mystery Library/
│   ├── Day 1/
│   │   ├── story.json
│   │   ├── foto.webp
│   │   ├── man/
│   │   │   ├── easy.mp3
│   │   │   ├── intermediate.mp3
│   │   │   └── challenge.mp3
│   │   └── woman/
│   │       ├── easy.mp3
│   │       ├── intermediate.mp3
│   │       └── challenge.mp3
│   ├── Day 2/
│   │   └── ...
│   └── Day 3/
│       └── ...
```

В `story.json` для Day 1:
```json
{
  "folder": "The Mystery Library/Day 1",
  "seriesDay": 1,
  "seriesTotal": 7,
  // ... остальные поля
}
```

## Проверка

После добавления новой истории:
1. Обновите страницу сайта
2. История должна появиться в списке историй
3. Картинка должна отображаться в карточке
4. При клике история должна открываться в модальном окне

## Автоматизация

Код автоматически:
- Загружает путь к картинке из поля `folder`
- Отображает картинки в карточках и модальном окне
- Поддерживает все уровни сложности
- Кеширует истории для быстрой загрузки

## Советы

1. **Используйте последовательные названия папок** - `Day 1`, `Day 2`, и т.д.
2. **Следите за полем `folder`** - оно должно точно соответствовать структуре папок
3. **Проверяйте порядок в stories.json** - новые истории должны быть в начале массива
4. **Оптимизируйте картинки** - используйте webp формат для лучшей производительности
5. **Группируйте по сериям** - каждая история в своей папке серии с днями внутри
